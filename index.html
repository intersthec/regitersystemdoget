คำถามที่พบบ่อย (FAQ)

ข้อสงสัยเกี่ยวกับบริการของเรา

รวมคำตอบสำหรับคำถามยอดฮิตเพื่อให้คุณเริ่มต้นใช้งานได้อย่างมั่นใจ

มีบริการทดลองใช้งานฟรีก่อนตัดสินใจซื้อหรือไม่?

มีครับ! เราเปิดให้ทดลองใช้งานระบบเต็มรูปแบบฟรี 14 วัน โดยไม่ต้องกรอกข้อมูลบัตรเครดิต ทีมงานของเราจะช่วยตั้งค่าระบบเริ่มต้นให้พร้อมใช้งานทันที

สามารถนำเข้าข้อมูลจากระบบเดิม (Excel / ระบบเก่า) ได้หรือไม่?

สามารถทำได้ง่ายดาย ระบบของเรารองรับการนำเข้าไฟล์ Excel, CSV หรือเชื่อมโยงผ่าน REST API โดยมีทีมผู้เชี่ยวชาญคอยอำนวยความสะดวกในการย้ายข้อมูล (Data Migration) ฟรี

ข้อมูลของบริษัทจะถูกจัดเก็บที่ไหน และปลอดภัยเพียงใด?

ข้อมูลทั้งหมดจัดเก็บในศูนย์ข้อมูล Tier 4 มาตรฐานสากล เข้ารหัส 256-bit AES มีการสำรองข้อมูลอัตโนมัติหลายระดับ และปฏิบัติตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA) อย่างเคร่งครัด

หากต้องการปรับแต่งระบบเฉพาะธุรกิจ สามารถทำได้หรือไม่?

สามารถทำได้ครับ สำหรับแพ็กเกจ Enterprise เรามีทีมซอฟต์แวร์เอ็นจิเนียร์ที่พร้อมวิเคราะห์และพัฒนาโมดูลพิเศษให้สอดคล้องกับ Workflow และโครงสร้างองค์กรของคุณอย่างลงตัว
